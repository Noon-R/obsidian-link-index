# Link Index Plugin

PureRef風の無限キャンバスでWebリンクやファイルを管理するObsidianプラグイン。MCP経由でClaudeやGitHub CopilotなどのAIから直接カードを追加できます。

## 基本操作

### リンク・ファイルの追加

**クリップボードからペースト（`Ctrl+V`）**  
クリップボードに `https://` で始まるURLがある状態でキャンバス上で `Ctrl+V` を押すと、OGPを自動取得してカードをビューポート中央に追加します。

**クイック追加モーダル（`Ctrl+N`）**  
URL・タイトル・タグを入力するモーダルが開きます。各フィールドで `Enter` を押すと次のフィールドに移動し、タグ欄で `Enter` を押すと確定します。

**ドラッグ&ドロップ**  
- ブラウザのリンクやタブをキャンバスにドロップ → OGPカードを生成
- ファイルエクスプローラーからファイルをドロップ → ファイルカードを生成（複数ファイル同時対応）
- PDFファイルのドロップ → PDFカードを生成（サムネイル非同期生成）

---

### カードの操作

**選択**  
- カードをクリックして単体選択
- 空白エリアをドラッグして範囲選択
- `Ctrl+A` で全選択

**移動・リサイズ**  
- 選択したカードをドラッグして移動
- カード端のリサイズハンドルをドラッグしてサイズ変更

**開く（ダブルクリック）**  
| カード種別 | 動作 |
|---|---|
| Webリンク | デフォルトブラウザで開く |
| Vault内ノート | Obsidianで開く |
| ローカルファイル | システムの既定アプリで開く |

**削除**  
選択して `Delete` または `Backspace`。

---

### ナビゲーション

| 操作 | 動作 |
|---|---|
| `Alt+ドラッグ` / 中クリックドラッグ | パン（視点移動） |
| `Ctrl+ホイール` | ズームイン・アウト |
| `F` | 全カードが収まるようにビューをフィット |
| `Escape` | 選択解除 / 検索バーを閉じる |

**ズーム別の描画密度**  
キャンバスをズームアウトするほど描画が省略され、大量カードでもパフォーマンスを保ちます。

| ズーム倍率 | 表示内容 |
|---|---|
| `< 0.2` | ステータスカラーの丸のみ |
| `0.2 – 0.45` | タイトル1行 + ステータスドット |
| `0.45 – 0.8` | ドメイン + タイトル + サムネイル |
| `≥ 0.8` | ドメイン + タイトル3行 + サムネイル + 説明文 + バッジ |

---

### 検索・絞り込み（`Ctrl+F`）

キャンバス上に検索バーが表示され、タイトル・URLをリアルタイムでフィルタリングします。マッチしないカードは半透明（12%の不透明度）になります。`Escape` または検索バーの閉じるボタンで終了します。

---

### 右クリックメニュー

クリックした対象によってメニュー内容が変わります。

**空白エリアを右クリック**
| 項目 | 動作 |
|---|---|
| リンクを追加... | クイック追加モーダルを開く |
| フレームを作成 | その位置にフレームを新規作成 |
| 自動レイアウト | タグ別にカードをグルーピング整列 |
| 全体を表示（F） | ビューをフィット |

**カードを右クリック**
| 項目 | 条件 | 動作 |
|---|---|---|
| ブラウザで開く | Webリンクのみ | デフォルトブラウザで開く |
| Obsidianで開く | Vault内ノートのみ | Obsidianで開く |
| 開く | ローカルファイルのみ | 既定アプリで開く |
| フォルダで表示 | ローカルファイルのみ | エクスプローラーでフォルダを開く |
| カードを編集 | 常時 | タイトル・タグ等を編集するモーダルを開く |
| ステータス変更 | 常時 | unread / reading / done / archive から選択（現在値に ✓） |
| 削除 | 常時 | カードをボードと cards/ から削除 |

**フレームを右クリック**
| 項目 | 動作 |
|---|---|
| フレームを編集 | ラベルとカラーを編集するモーダルを開く |
| フレーム内を全選択 | フレーム内の全カードを選択 |
| フレームを削除 | フレームを削除（内部カードは残る。システムフレームは削除不可） |

---

### カードのステータス

カードには4つのステータスがあり、右クリックメニューまたはカード編集モーダルから変更できます。ズームアウト時もステータスカラーで状態を把握できます。

| ステータス | カラー | 意味 |
|---|---|---|
| `unread` | グレー | 未読 |
| `reading` | オレンジ | 読んでいる |
| `done` | グリーン | 読了 |
| `archive` | ダークグレー | アーカイブ |

---

### フレーム

カードをグループ化するための領域です。

- **作成**: 空白エリアを右クリック →「フレームを作成」、または自動レイアウト実行時に自動生成
- **編集**: フレームを右クリック →「フレームを編集」でラベルとカラー（10色）を変更可能
- **削除**: フレームを右クリック →「フレームを削除」（フレーム内のカードは残ります）
- **「AI Inbox」フレーム**: システム予約フレーム。MCPからURLを追加した際のデフォルト配置先。削除不可。

---

### 自動レイアウト（`Ctrl+Shift+L`）

カードのタグを基準に自動でグルーピングし、格子状に整列します。同じタグを持つカードは同じフレームにまとめられ、タグ名からフレームカラーが自動決定されます。

## AIとの連携（MCP Server）

`link-index-mcp` はMCP標準プロトコル（JSON-RPC 2.0 over stdio）で動作するRustサーバーです。ClaudeとGitHub Copilotの両方から同じサーバーを利用します。

### 前提条件

- [Rust](https://rustup.rs/) がインストールされていること

### ビルド

```sh
cd link-index-mcp
cargo build --release
```

バイナリが `link-index-mcp/target/release/link-index-mcp(.exe)` に生成されます。

---

### GitHub Copilot（VS Code）

`.vscode/mcp.json` が設定済みです。

1. VS Code でこのフォルダーをワークスペースとして開く
2. GitHub Copilot Chat を開く
3. 初回接続時に VS Code が **Obsidian vault のパス** を入力プロンプトで尋ねます

環境変数 `OBSIDIAN_VAULT` を vault のパスに設定しておくと自動入力されます。

```sh
# PowerShell
$env:OBSIDIAN_VAULT = "D:\path\to\your\vault"

# bash / zsh
export OBSIDIAN_VAULT="/path/to/your/vault"
```

Copilot Chat の会話例:

```
Link Index に https://example.com を追加して
AI Inbox のカード一覧を見せて
フレーム一覧を表示して
```

---

### Claude Desktop

`claude_desktop_config.json`（`%APPDATA%\Claude\` または `~/Library/Application Support/Claude/`）の `mcpServers` に追加します:

```json
{
  "mcpServers": {
    "link-index": {
      "command": "D:\\path\\to\\link-index-mcp\\target\\release\\link-index-mcp.exe",
      "args": ["--vault", "D:\\path\\to\\your\\vault"]
    }
  }
}
```

macOS / Linux の場合はパスを適宜変更し、`.exe` は不要です。

---

### Claude Code（CLI）

```sh
claude mcp add link-index \
  "D:/path/to/link-index-mcp/target/release/link-index-mcp" \
  --args "--vault" "D:/path/to/your/vault"
```

---

### 利用可能なMCPツール

| ツール名 | 説明 | 主なパラメータ |
|---|---|---|
| `add_link` | URLをOGP取得してカード追加 | `url`（必須）, `group`, `title`, `tags` |
| `list_frames` | フレーム一覧とカード数を表示 | なし |
| `list_cards` | フレーム内のカード一覧を表示 | `frame`（省略時: AI Inbox） |
| `remove_card` | カードをボードから削除 | `id`（必須、ULID） |
